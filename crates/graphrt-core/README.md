# graphrt-core

Executor-agnostic graph runtime for agentic AI workflows: graph model, variable pool, scheduler, events, snapshots and built-in control nodes.

Part of [graphrt](https://github.com/BimaPangestu28/graphrt) — **run your agent everywhere**: one small runtime for
agentic AI workflows on servers, containers, the edge and phones.

```toml
[dependencies]
graphrt-core = "0.6"
```
