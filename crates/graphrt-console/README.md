# graphrt-console

Admin console for self hosted graphrt servers: OIDC sign in, roles, an audit log, encrypted secrets and an agent registry with environments.

Part of [Graphrt](https://github.com/Graphrt/graphrt): **run your agent everywhere**. One small runtime for
agentic AI workflows on servers, containers, the edge and phones.

`graphrt serve --console console.yaml` uses it when `graphrt-cli` is built with the `console` feature.

```toml
[dependencies]
graphrt-console = "0.6"
```
