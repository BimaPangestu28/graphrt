# graphrt-connect

Knowledge connectors for graphrt: keep knowledge bases in sync with web sites, REST APIs, Google Drive, Notion and SharePoint, incrementally and on a schedule.

Part of [graphrt](https://github.com/Graphrt/graphrt): **run your agent everywhere**: one small runtime for
agentic AI workflows on servers, containers, the edge and phones.

```toml
[dependencies]
graphrt-connect = "0.6"
```
