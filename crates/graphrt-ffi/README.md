# graphrt-ffi

Embedding API for mobile and desktop apps (Kotlin, Swift, Python...) via
UniFFI: run Graphrt workflows inside an app, with native tools of the app
(`ToolProvider`), typed run events, approvals (`PausedRun`), skills, learning,
a file workspace and checked UI blocks.

Part of [Graphrt](https://github.com/Graphrt/graphrt), **run your agent everywhere**: one small runtime for
agentic AI workflows on servers, containers, the edge and phones.

```toml
[dependencies]
graphrt-ffi = "0.6"
```

The Android AAR and the Swift package built from this crate are attached to
every GitHub release (`sdk/android`, `sdk/swift`).
