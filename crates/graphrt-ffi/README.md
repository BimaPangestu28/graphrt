# graphrt-ffi

Embedding API for mobile and desktop apps (Kotlin, Swift, Python...) via UniFFI.

Part of [graphrt](https://github.com/BimaPangestu28/agentic-rust-runtime) — **run your agent everywhere**: one small runtime for
agentic AI workflows on servers, containers, the edge and phones.

```toml
[dependencies]
graphrt-ffi = "0.1"
```
