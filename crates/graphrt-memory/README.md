# graphrt-memory

Long term memory for graphrt agents: notes per tenant, agent and user, a write gate against secrets and planted text, keyword and optional semantic recall, files only.

Part of [graphrt](https://github.com/Graphrt/graphrt) — **run your agent everywhere**: one small runtime for
agentic AI workflows on servers, containers, the edge and phones.

```toml
[dependencies]
graphrt-memory = "0.6"
```
