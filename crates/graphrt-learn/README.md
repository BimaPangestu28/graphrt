# graphrt-learn

Self learning for graphrt agents: short lessons with provenance, isolated per agent and user, approved by a person before they are used.

Part of [graphrt](https://github.com/Graphrt/graphrt) — **run your agent everywhere**: one small runtime for
agentic AI workflows on servers, containers, the edge and phones.

```toml
[dependencies]
graphrt-learn = "0.6"
```
